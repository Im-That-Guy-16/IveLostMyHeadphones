## Overview

A self-contained custom stylesheet package for a music site profile, built on the
shared Project STMPE design language. It installs through the site's custom
stylesheet field or a userstyle manager such as Stylus.

An optional userscript adds editor enhancements on top of the theme.

## Contents

| Path | Purpose |
|---|---|
| `Project-STMPE.css` | The main stylesheet |
| `RED-Enriched.user.js` | Optional userscript for editor enhancements |
| `assets/genre-icons/` | Local SVG assets referenced by the stylesheet |

## Install

**Stylesheet** — once GitHub Pages has published, use the Pages URL for
`Project-STMPE.css` as the hosted stylesheet URL in your profile settings, or load
the file in a userstyle manager such as [Stylus](https://add0n.com/stylus.html).

**Userscript (optional)** — install the published `RED-Enriched.user.js` with
[Tampermonkey](https://www.tampermonkey.net/) or [Violentmonkey](https://violentmonkey.github.io/).
